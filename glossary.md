# CCNA Glossary

## Access Control List (ACL)
A list used to permit or deny traffic based on defined rules.

## Area 0
The OSPF backbone area in which all other areas usually connect.

## Broadcast
Traffic sent to all devices on a network segment.

## Default Gateway
The network device used to send traffic outside the local subnet.

## DHCP
Dynamic Host Configuration Protocol automatically assigns IP addresses.

## DNS
Domain Name System converts names to IP addresses.

## EtherChannel
A method to bundle multiple physical links into a single logical link.

## Interface Up/Down
A status indication showing whether a network interface is active.

## MAC Address
A hardware address used at Layer 2 for Ethernet communication.

## NAT
Network Address Translation converts private IPs to public IPs.

## OSPF
Open Shortest Path First, a dynamic link-state routing protocol.

## Ping
A command used to test end-to-end reachability.

## Router
A device used to forward packets between different networks.

## Subnet Mask
A value used to identify the network bits and host bits in an IP address.

## Switch
A LAN device that forwards frames based on MAC addresses.

## VLAN
A logical segmentation of a LAN.

## Wi-Fi
Wireless network communication based on IEEE 802.11 standards.
