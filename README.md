# CCNA Full Course Study Repository

This repository is a practical study pack for Cisco CCNA 1, 2, and 3, structured for NetAcad-style learning, troubleshooting practice, labs, and command review.

It includes:
- CCNA 1 notes
- CCNA 2 notes
- CCNA 3 notes
- Cisco command reference
- Troubleshooting and labs
- Simple study agent

## Repository structure

- `ccna1/README.md` - CCNA 1 fundamentals
- `ccna2/README.md` - switching and routing essentials
- `ccna3/README.md` - advanced routing, security, and troubleshooting
- `commands/cisco_commands_reference.md` - full command list
- `labs/ccna_lab_checklist.md` - labs and practical exercises
- `study_agent/ccna_study_agent.py` - interactive study helper
- `glossary.md` - key networking vocabulary

## Why this repo is useful

- Built for self-study and revision
- Organized by course level
- Strong focus on practical command use and troubleshooting
- Includes real-world lab scenarios and quick review questions

## Suggested study path

1. Start with `ccna1/README.md`
2. Continue with `ccna2/README.md`
3. Finish with `ccna3/README.md`
4. Use `commands/cisco_commands_reference.md` as your command lookup guide
5. Practice using `labs/ccna_lab_checklist.md`
6. Use the study agent for quick topic reviews

## Quick start

```bash
cd study_agent
python3 ccna_study_agent.py
```

## Notes

This repository is intentionally designed as a field-ready learning pack, not just a summary sheet. It is useful for both exam preparation and hands-on networking practice.
